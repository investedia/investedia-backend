# Source schemas and identifiers

Not investment advice. These are documented schema families, not a claim that a
fresh response has been checked locally. `source-evidence.json` from the manual
runner records actual observed paths, status, retrieval time and hashes. Current
terms and schema versions still require review before production ingestion.

| Source | Real field families / identifiers | Cadence | Audit/download method and limits |
|---|---|---|---|
| Wikidata | QID; P414 stock-exchange statement; qualifier P249 ticker; P1278 LEI; P5531 CIK; P946 ISIN; P159 HQ entity and its P625 coordinates; P452 industry | Continuously edited; dump schedules separate | Bounded SPARQL, LIMIT 25 by default/max 100. A ticker and exchange must come from the SAME qualified listing statement. The alternative P249 statement qualified with P414 must also be considered later. Never cross-join independent tickers/exchanges. No assumed native MIC/FIGI guarantee. |
| GLEIF Level 1 | LEI; LegalName; EntityStatus; LegalAddress, HeadquartersAddress; RegistrationAuthorityID/RegistrationAuthorityEntityID; LegalJurisdiction; registration/update/renewal dates and validation metadata | Golden Copy/deltas and API updates | Golden Copy publication manifest plus bounded API schema sample. National registry identifiers are not automatically CIK/ISIN. HeadquartersAddress is an address, not coordinates. |
| GLEIF Level 2 | StartNode/EndNode NodeID (usually LEI); RelationshipType; relationship/status/registration periods; validation/source references; reporting exceptions | Relationship Golden Copy/deltas | Direct/ultimate accounting-consolidation parent relationships. API relationship link or RR-CDF bulk XML; sample availability is not a population estimate. |
| SEC submissions | CIK, name, tickers[], exchanges[], SIC/SIC description, business/mailing addresses; filings.recent accessionNumber, form, filingDate, reportDate, primaryDocument | As filings arrive; nightly bulk archive | Submissions ZIP metadata and one bounded existing-CIK API sample. Ticker/exchange arrays may have different cardinalities: never zip or cross-join them by assumption. The SEC company_tickers_exchange.json file provides explicit row fields (cik, name, ticker, exchange) for a separate bounded schema probe; its exchange label still needs a reviewed MIC map and security type. Business address is not automatically HQ. |
| SEC companyfacts | cik/entityName; facts[taxonomy][concept].units[unit][] with val, start/end, fy/fp, form, filed, accn, frame | As filings arrive; nightly bulk archive | Companyfacts ZIP metadata and a bounded CIK JSON sample. No ISIN/LEI/MIC guarantee. Numerical concepts are not a price feed. |
| ESMA FIRDS | FinInstrmGnlAttrbts: Id (ISIN), FullNm, ShrtNm, ClssfctnTp (CFI), NtnlCcy; issuer LEI; TradgVnRltdAttrbts/Id (venue MIC), admission/trading/termination dates | Full and delta files, typically daily business process | Official FIRDS full/delta file catalogue, then a versioned schema/file sample after terms and manifest are identified. Exact namespace/XSD must be captured. Venue MIC is not necessarily operating MIC. No generic ticker/FIGI guarantee. |
| Nasdaq Trader | nasdaqlisted: Symbol, Security Name, Market Category, Test Issue, Financial Status, Round Lot Size, ETF, NextShares; otherlisted: ACT Symbol, Exchange, CQS Symbol, NASDAQ Symbol, Security Name, ETF, Test Issue | Daily directory, creation-time footer | Whole small directory for schema audit only until rights cleared. Remove footer/test issues. ETF=N alone does NOT prove common stock: preferred shares, units, rights/warrants and receipts need classification. Venue-letter-to-MIC map requires the directory definitions. |
| ECB | Cube@time; currency ISO4217 and rate = units per EUR | ECB publication days, reference rates | Single 90-day historical XML. Keep dates, quote direction, publication gaps and source. No transaction price or capital-flow field. |
| World Bank WDI | country ISO identifiers; indicator id; date/year; value; unit/source metadata. Country endpoint also provides capital coordinates | Annual/periodic indicators; revisions vary | Bulk indicator API with complete pagination/dataset licence. Capital coordinates must NEVER become company HQ. |
| exchange-calendars 4.13.2 | calendar name/MIC alias, IANA zone, effective regular open/close/break times, sessions/holidays/early closes | Library releases | Already retained Apache-2.0 licence/notices and dated snapshots in the repo. Aliases must be explicit library aliases; unsupported MICs remain unknown. Emergency closures can differ. |
| UK Companies House | company_number, company_name, company_status/type, SIC, incorporation date, registered office, accounts/confirmation dates; separate PSC/filing products | Bulk product/monthly snapshot; API reflects changes | Keyless free bulk-product manifest. Authenticated API excluded. Company number is not CIK/LEI; registered office is not HQ; PSC is not a worldwide ownership graph. |
| JSE / NGX / B3 / NSE India | Dataset-specific issuer/security/listing fields, often local code/ISIN; do not assume all have LEI, HQ or MIC | Depends on the officially licensed file | Exact reusable listing products not cleared. No invented download URL or undocumented scraping. Only add after explicit product-specific terms. |

Bulk sources can be multi-gigabyte. This audit captures SEC bulk HEAD metadata
and the GLEIF publication manifest rather than silently downloading/building a
registry. The SEC schema probe is Apple CIK 0000320193, already in saved data:
a **single biased schema sample**, not proof of reliable coverage across filers,
industries, IFRS, countries or exchanges. Sample limits never imply completeness.
