# Share-card fonts

Unmodified Inter 4.1 static OpenType fonts from the official rsms/inter release:
https://github.com/rsms/inter/releases/tag/v4.1

Bundled weights: Bold, Medium, SemiBold, as required by update_share_cards.py.

The OFL permits bundling and redistribution with software; these fonts are not sold separately or renamed/modified.
No runner-installed fonts or network downloads are needed for rendering.
